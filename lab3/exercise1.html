Exercise 1: JSON Structure

JSON Observations

JSON stores information using different names and values. Objects use curly brackets and arrays square brackets. Also, JSON can have objects and arrays INSIDE of other objects.

JSON Examples

Name/Value Pair: "title": "Example Book"

Object:

{
    "title": "Example Book",
    "price": 20
}

Array:

[
    "Book 1",
    "Book 2"
]

Nested Structure:

{
    "library": {
        "books": [
            "Book 1",
            "Book 2"
        ]
    }
}
